# PHISHGUARD — Think Before You Click

**PHISHGUARD** is an interactive phishing-awareness website designed to help people recognize online scams, understand common phishing techniques, and develop safer online habits.

The project combines cybersecurity education with interactive examples and quizzes to make learning about phishing more accessible and engaging.

## Features

- **Phishing Awareness:** Learn what phishing is, how it works, and the different forms it can take.
- **Warning Signs:** Understand common red flags in suspicious messages, including urgent language, misleading links, and requests for sensitive information.
- **Interactive Examples:** Explore fictional messages and learn which warning signs they contain.
- **Knowledge Quiz:** Test your understanding of phishing through an interactive quiz with explanations.
- **Message Analyzer:** Explore a basic educational tool that highlights potential warning signs in text messages.
- **Responsive Design:** Access the website on desktop and mobile devices.

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No backend or database is required for the frontend version.

## Important Disclaimer

PHISHGUARD is an educational project, not a professional security product.

The message analyzer is a basic educational tool and may produce incorrect results. A message without obvious warning signs is not necessarily safe, and a suspicious-looking message is not necessarily malicious. Always verify unexpected requests through trusted channels.

Do not enter passwords, confidential information, or private messages into the analyzer.
